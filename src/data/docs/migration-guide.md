# How to migrate your lyrite v1 data

lyrite version 2 is a complete rewrite of the app. While v1 stored your songs locally in your browser, v2 uses accounts and a database so your songs can be available anywhere you sign in.

Unfortunately, there isn't currently an automatic migration from v1 to v2, so you'll need to copy each song manually.

## 1 - Export your v1 songs

{{LOCAL_STORAGE_EXPORT}}

## 2 - Import your songs into v1.lyrite.com

1. go to [v1.lyrite.com](https://v1.lyrite.com)
2. click **Import Songs**
3. select the file you downloaded in the previous step

Your v1 songs should now be available at v1.lyrite.com. You can use v1 as long as you like, I don't plan on shutting it down.

## 3 - Copy your songs to lyrite version 2

1. [create an account](/login) on lyrite version 2
2. [create a new song](/songs/new)
3. copy the lyrics from your song in v1 and paste them into the new song in v2
4. repeat for each song you want to migrate
