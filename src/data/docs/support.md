# Lyrite Support


## Import/export issues

If an import or export is failing, open the browser dev tools and check the application storage in Local Storage.

- Open DevTools in your browser (F12).
- Go to the Application or Storage tab.
- Look for Local Storage entries related to Lyrite.
- Export or clear out the entries - this might delete your Lyrite v1 songs!


## Login issues

### Not logged in after successful login redirect

- Open DevTools.
- Go to Application > Storage.
- Find the site under Shared Storage or Storage.
- Clear the stored data for Lyrite.
- Refresh the page and try logging in again.


## Still stuck?

You can submit a support request via [GitHub Issues](https://github.com/kevinkace/lyrite/issues).
