# Announcing Lyrite version 2!

## At long last, Lyrite version 2 is live! 🎉

Lyrite started as a small hobby tool for me and my bandmates - we wanted an easy way to display lyrics with simple formatting while jamming. Now it's grown into a fully fledged web app ready for everyone.

## New in version 2

* **Accounts** - Sign in with email or a third-party provider and keep your songs synced wherever you use Lyrite.
* **An updated editor** - All the same features v1, plus the ability to choose from different typefaces.
* **Your own profile** - See all your songs in one place, with the ability to make songs private or delete them.

You can see the full list of changes in the [Release Notes](/docs/release-notes).

## Already have songs in Lyrite v1?

No problem! You can bring your existing songs over to v2. See the [v1 migration guide](/docs/migration-guide) for instructions.
